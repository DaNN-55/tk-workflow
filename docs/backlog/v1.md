# v1 实施清单

不需要在 v1 引入 Jira 或 Linear。此文件是仓库中的唯一 ticket 来源；每个 ticket 完成后在同一分支提交，并在本文件更新状态。

- [ ] T-001 初始化应用骨架、环境变量约定和本地开发命令。
- [ ] T-002 定义 Supabase Schema：账号、蓝图、Episode、任务、产物、审批、审计和实验。
- [ ] T-003 实现受控状态迁移接口和不可变审计事件。

## 建议的第一个实现批次

只做 T-001 至 T-005。验收标准是：可以创建两个相互隔离的账号、为任一账号创建 Episode、提交脚本产物、在本地审批台批准或驳回，并看到完整审计记录。
